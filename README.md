# FI5699 Dissertation Module — Python Code

Code repository for **FI5699 Dissertation Module**, Department of Finance, University of St Andrews.

## Getting Started

Click the button below to open this repository in a ready-to-use cloud environment with Python, all packages, and an AI coding assistant pre-installed. No setup required.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/christian-engels/fi5699-code)

Alternatively, if you have Docker and VS Code installed locally, you can clone this repository and open it in a [Dev Container](https://code.visualstudio.com/docs/devcontainers/containers).

## What's Included

The dev container comes with:

| Tool | What it does |
|------|-------------|
| Python 3.12 | Programming language |
| uv | Package and project manager |
| polars | DataFrames (like a supercharged spreadsheet) |
| plotnine | Plotting (ggplot2 for Python) |
| pyfixest | Regressions (like Stata's `reghdfe`) |
| diff-diff | Difference-in-differences |
| tidyfinance | Financial data utilities |
| xlsxwriter | Excel file writing |
| pyarrow | Fast data serialisation |
| marginaleffects | Marginal effects, predictions, and contrasts |
| OpenCode | AI coding assistant in the terminal |
| GitHub Copilot | AI coding assistant in the editor |
