# Week 4: Working with Data in Python

Companion scripts for the Week 4 lecture. Each file matches a section of the slides.

## Files

| Script                           | Topic                                             |
| -------------------------------- | ------------------------------------------------- |
| `01_data_structures.py`          | DataFrames, Series, data types, inspection        |
| `02_reading_writing_data.py`     | CSV and Excel I/O with Polars                     |
| `03_expressions_contexts.py`     | `select`, `with_columns`, `filter`, `group_by`    |
| `04_working_with_expressions.py` | Arithmetic, comparisons, conditionals             |
| `05_real_stock_data.py`          | Downloading Yahoo Finance data, computing returns |
| `06_combining_dataframes.py`     | Joins and concatenation                           |
| `07_reshaping_data.py`           | Pivot and unpivot                                 |
| `08_visualising_data.py`         | Plotting with plotnine                            |

## Getting Started

1. Navigate to this folder in the terminal:

   ```bash
   cd week-4
   ```

2. Open any `.py` file and run it line-by-line with **Ctrl+Enter** (or **Cmd+Enter** on Mac), just like you learned in Week 2.

   You can also run a full script from the terminal:

   ```bash
   python 01_data_structures.py
   ```

Work through the scripts in order (01 through 08) to see the concepts from the lecture applied in more detail.
